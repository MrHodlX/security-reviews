# Security reviews of open-source Bitcoin software

By MrHodl ([@MrHodl](https://x.com/MrHodl) on X). Every finding named below
is public or fixed; reports still under embargo are counted, not named.

## What we do

We review open-source Bitcoin software: wallets, signers, PSBT tools and
servers. Several AI models attack each codebase independently, then every
claim is checked against the code, the relevant BIP or the project's own test
vectors, and traced through the code paths, before anything is reported. We
read the code; we don't build or run it, and our reports say so. Most of what
models produce does not survive that step, and that filtering is what
maintainers get from us: fewer, real findings. We look hardest at what other
reviews skip: crafted inputs (files, QR codes, PSBTs) that lie about
themselves, and code that should fail closed but does not. We report
privately first, through each project's security policy, and never test live
systems.

## Accuracy

Of the 81 public Faraday audit findings, about 7 in 10 led to a fix and 1 in
10 did not hold. The maintainer also triaged 91 lower-confidence items we
flagged separately: 55 led to fixes and 30 did not hold. We publish these
numbers because a review is only useful if its findings are real.

Checking costs us findings, and we accept that. In one November audit the
models' cross-checks agreed on 86 findings, one of them rated critical; read
against the source, the critical did not hold and went out as a low-severity
note.

## Our own project

[EntropyLab](https://github.com/OogaBoogaX/entropylab), our offline Bitcoin
key tool, gets the same model review on every change: DeepSeek V4.1, Kimi K3,
GLM 5.3, MiniMax M3.1 Flash and Nemotron 3.5 Lightning, plus a red-team pass.
Changes that handle keys also get a second red team by Kimi K3.1, plus a Codex
or Grok review. Because it is our own code, it also gets tests we only run on
our own code: mutation runs, and a harness that captures what secrets a browser
leaves in memory. The rounds and the fixes they produced are logged in
[entropylab-red-team.md](entropylab-red-team.md).
